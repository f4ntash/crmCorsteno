# Mármol Blanco — Surface Material Assets

Local 1K PBR maps for the Revestimientos 3D demo. The files are loaded on
demand by URL and remain outside the JavaScript bundle.

- `basecolor.webp` — 1024 × 1024 RGB, sRGB, 90 KB.
- `normal.webp` — 1024 × 1024 tangent-space OpenGL normal, linear/no color space, 387 KB.
- `roughness.webp` — 1024 × 1024 grayscale, linear/no color space, 156 KB.

Source: [Marble 01](https://polyhaven.com/a/marble_01), Poly Haven, CC0
([license](https://polyhaven.com/license)). The source page reports a 1.50
m-wide material; the square local map is calibrated as a 1.50 m × 1.50 m full
repeat area with no UV rotation.
