# Piedra Gris Andina — Surface Material Assets

Local 1K PBR maps for the Revestimientos 3D demo. The files are loaded on
demand by URL and remain outside the JavaScript bundle.

- `basecolor.webp` — 1024 × 1024 RGB, sRGB, 150 KB.
- `normal.webp` — 1024 × 1024 tangent-space OpenGL normal, linear/no color space, 1.24 MB.
- `roughness.webp` — 1024 × 1024 grayscale, linear/no color space, 121 KB.

Source: [Stone Tile Wall](https://polyhaven.com/a/stone_tile_wall), Poly Haven,
CC0 ([license](https://polyhaven.com/license)). The source page reports a
2.00 m-wide material; the square local map is calibrated as a 2.00 m × 2.00 m
full repeat area with no UV rotation.
