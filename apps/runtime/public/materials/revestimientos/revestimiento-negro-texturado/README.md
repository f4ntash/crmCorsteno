# Revestimiento Negro Texturado — Surface Material Assets

Local 1K PBR maps for the Revestimientos 3D demo. The files are loaded on
demand by URL and remain outside the JavaScript bundle.

- `basecolor.webp` — 1024 × 1024 RGB, sRGB, 120 KB.
- `normal.webp` — 1024 × 1024 tangent-space OpenGL normal, linear/no color space, 1.27 MB.
- `roughness.webp` — 1024 × 1024 grayscale, linear/no color space, 342 KB.

Source: [Black Painted Planks](https://polyhaven.com/a/black_painted_planks),
Poly Haven, CC0 ([license](https://polyhaven.com/license)). The source page
reports a 1.60 m-wide material; the square local map is calibrated as a 1.60 m
× 1.60 m full repeat area and rotated 90° for vertical planks.
