# Cemento Arena — Surface Material Assets

Local 1K PBR maps for the Revestimientos 3D demo. The files are loaded on
demand by URL and remain outside the JavaScript bundle.

- `basecolor.webp` — 1024 × 1024 RGB, sRGB, 341 KB.
- `normal.webp` — 1024 × 1024 tangent-space OpenGL normal, linear/no color space, 1.59 MB.
- `roughness.webp` — 1024 × 1024 grayscale, linear/no color space, 484 KB.

Source: [Concrete Floor](https://polyhaven.com/a/concrete_floor), Poly Haven,
CC0 ([license](https://polyhaven.com/license)). The source page reports a
2.10 m-wide material; the square local map is calibrated as a 2.10 m × 2.10 m
full repeat area with no UV rotation.
