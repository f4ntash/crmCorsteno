# Panel Nórdico Claro — Surface Material Assets

Local 1K PBR maps for the Revestimientos 3D demo. The files are loaded on
demand by URL and remain outside the JavaScript bundle.

- `basecolor.webp` — 1024 × 1024 RGB, sRGB, 315 KB.
- `normal.webp` — 1024 × 1024 tangent-space OpenGL normal, linear/no color space, 1.19 MB.
- `roughness.webp` — 1024 × 1024 grayscale, linear/no color space, 745 KB.

Source: [Kitchen Wood](https://polyhaven.com/a/kitchen_wood), Poly Haven,
CC0 ([license](https://polyhaven.com/license)). The source page reports a
0.60 m-wide material; the local square map is calibrated as a 0.60 m × 0.60 m
repeat area and rotated 90° for the panel's vertical orientation.
